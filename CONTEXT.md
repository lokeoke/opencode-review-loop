# Vocabulary

- **Run:** One explicitly started, bounded review-and-fix workflow.
- **Round:** One completed review of a particular code fingerprint.
- **Fixer:** The user's existing implementation session.
- **Reviewer:** A separate session that inspects changes without editing project files.
- **Blocking finding:** A supported blocker or major defect that prevents a passing outcome.
- **Code fingerprint:** The identity of the source state on which review and verification rely.
- **Check:** A user-approved verification command.
- **Worktree:** An independent Git checkout; the unit of exclusive run ownership.
